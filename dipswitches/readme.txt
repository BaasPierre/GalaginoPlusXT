The dipgen.py will generate your dipswitches.h file
Example: we are finding dipswitches for gng (the real mame zip game name) this case for game Ghost n Goblins
Place extracted game folder as gng in this same directory where dipgen.py is.

Use Windows cmd prompt to this directory where the dipgen is
run command: python dipgen.py gng

The file will be generated in this same directory where dipgen.py is
Copy the generated file to your machine directory
